# Amazon Product Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing Amazon product data using MySQL. The analysis explores product pricing, discounts, customer ratings, rating counts, product popularity, and category performance using SQL queries.

## 🎯 Objective

The main objective of this project is to extract meaningful insights from Amazon product data using SQL.

The analysis focuses on:

- Product pricing
- Discount patterns
- Customer ratings
- Product popularity
- Category performance
- Customer savings

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 📂 Dataset

The dataset contains Amazon product and customer review information, including:

- Product ID
- Product Name
- Category
- Actual Price
- Discounted Price
- Discount Percentage
- Customer Rating
- Rating Count
- Customer Reviews
- User Information
- Review Information
- Product Links

The dataset was sourced from Kaggle.

## 🔍 Analysis Performed

The project includes SQL analysis to:

- Find the top 10 products with the highest discounted prices
- Calculate average ratings for each product category
- Identify highly rated products with more than 1,000 ratings
- Find products with the highest discount percentages
- Compare average actual and discounted prices by category
- Identify products with a price difference greater than ₹1,000
- Find products with the highest number of ratings
- Identify categories with an average rating greater than 4.0
- Analyze products offering discounts of 50% or more
- Find the most expensive products based on actual price
- Identify the category with the highest average discount
- Find highly rated products with more than 5,000 ratings
- Calculate customer savings from discounts
- Identify products with ratings higher than the overall average
- Identify categories with an average rating above 4.0 and more than 10 products
